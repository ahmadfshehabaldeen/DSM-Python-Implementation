# Double-Angle Summation Method (DSM)

This repository contains the official Python implementation and Monte Carlo validation script for the Direct Sinusoidal Method (DSM).

## Repository Contents
* `DSM_Simulation.py`: The unified code containing both the core implementation (`dsm_summation` and `rotational_sensitivity`) and the 10,000-system Monte Carlo validation simulation.

## Prerequisites
To run this code, you need:
* Python 3.x
* NumPy

## How to Run
To run the simulation and validate the numerical equivalence and rotational sensitivity results, execute the following command in your terminal:
```bash
python DSM_Simulation.py
